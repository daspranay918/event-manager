# 🚀 NextMeet

NextMeet is a modern event platform designed to help students discover, create, and manage college events in a simple and structured way.

---

## 📱 What is NextMeet?

NextMeet focuses on solving common problems in event platforms like:

* Difficulty finding relevant events
* Lack of proper event organization
* Poor communication between participants

It provides a clean and focused experience built specifically for student communities.

---

## ✨ Features

* 🔐 User Authentication
* 🎟 Create and Discover Events
* 👥 Join Events with seat tracking
* 💬 Event-based group chat
* 👤 Profile management

---

## 🎯 Focus

The platform currently focuses on **college tech events**, with plans to expand to broader communities in the future.

---

## ⚙️ Tech Stack

* Flutter
* Supabase
* PostgreSQL
